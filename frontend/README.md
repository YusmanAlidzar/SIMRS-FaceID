# SIMRSUD Admin / Kiosk

## Setup
1. Pastikan Node.js sudah terpasang
2. Buka terminal:
    // Admin
   - `cd .../frontend/admin-app`
   - `npm install`
   - `npm run dev`
   - buka `http://localhost:3001/`
    // Kiosk
   - `cd .../frontend/kiosk-app`
   - `npm install`
   - `npm run dev`
   - buka `http://localhost:3000/`
